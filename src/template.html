Comment demander mon fichier Spotify ?
  1. Ouvrez la page « Confidentialité du compte » de Spotify (bouton ci-dessous) et connectez-vous.
  2. Dans la partie pour télécharger vos données, cochez seulement l'historique de streaming étendu, puis envoyez la demande.
  3. Confirmez la demande avec le lien reçu par e-mail.
  4. Après quelques jours (jusqu'à 30), un e-mail vous prévient que vos données sont prêtes. Cliquez sur le bouton de téléchargement et connectez-vous : le fichier .zip se télécharge.
Ouvrir la page Spotify « Confidentialité du compte » L'aide de Spotify sur vos données

            Confidentialité de vos données

            • Votre fichier est lu par votre navigateur, sur votre appareil. Il n'est jamais envoyé à OneClient ni à personne d'autre, et rien n'est conservé quand vous fermez la page. Vous pouvez le vérifier : ouvrez la page, coupez votre connexion, puis chargez votre fichier. L'outil fonctionne toujours.
            • La page interdit à votre navigateur toute connexion vers l'extérieur : même par erreur, rien ne peut partir.
            • Le fichier de Spotify indique l'adresse IP de chaque écoute : l'outil ne la lit jamais.
            • Cette page n'utilise ni cookie ni script de mesure d'audience. Le serveur compte seulement le nombre de visites par jour, sans enregistrer d'adresse IP. Comme pour tout site web, l'hébergeur enregistre dans ses journaux techniques l'adresse IP et l'heure de chaque visite de la page ; ces journaux ne contiennent rien de votre fichier.
            • Si vous cliquez vers une autre page de oneclient.be, votre navigateur lui indique que vous venez de cet outil. Les autres sites, Spotify compris, ne reçoivent pas cette information.

            Avertissement

            • Cet outil donne une estimation, à titre indicatif, à partir de votre historique et des prix que vous indiquez. Ce n'est ni un conseil financier ni un conseil juridique.
            • Les prix des services changent : vérifiez-les avant de décider. Les résultats dépendent aussi de l'exactitude du fichier fourni par Spotify.
            • OneClient ne peut être tenu responsable d'une décision prise sur la base de ces résultats, ni d'une erreur de lecture du fichier. La décision vous appartient.
